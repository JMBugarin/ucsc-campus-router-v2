# data/

The campus data the app ships. After changing a file here, run `scripts/sync_app_data.sh`: it copies `buildings.json`, `rooms.json`, `search_aliases.json` and `holidays.json` into `app/assets/data/`, and a test fails if the copies differ.

- `building_sources.json` — hand-edited. One entry per building: `id`, display `name`, `osm_name` (exact OpenStreetMap name), `facility_ids` (links the building to rooms in `classrooms.json`), and `aliases` (extra names; the official schedule names are added automatically). `osm_name: null` means no location is known yet.
- `classrooms.json` — generated by `data-pipeline/fetch_classrooms.py` from https://classrooms.ucsc.edu/ (each room's official schedule name, "AIS Display Name", and facility id) and the public classroom-points layer behind https://maps.ucsc.edu/ (each room's lat/lon and level). The fetcher waits as long as the site's `robots.txt` asks.
- `buildings.json` — generated by `data-pipeline/build_buildings.py`. Adds `centroid` and `entrances` from OpenStreetMap. Do not hand-edit; change the sources file and regenerate.
- `search_aliases.json` — extra names the search accepts, by building id (for example `BE`).
- `holidays.json` — each term's first and last day and its no-class days, from the registrar's calendar. Add the next term by hand.
- `rooms.json` — hand-checked arrival guides, keyed `"<building-id>:<ROOM>"`. Every field is optional, but anything here must say when someone checked it on foot. An `entrance` is the door both apps send people to for that room:

  ```json
  {"overrides": {"baskin-engineering:152": {
    "access": "outside",
    "entrance": {"lat": 37.0003, "lon": -122.0634, "label": "Courtyard door by the bike racks"},
    "floor": "1",
    "wing": "North wing",
    "note": "Corner room facing the trees",
    "steps": ["Through the glass doors", "Second door on the left"],
    "step_free": true,
    "elevator": "Just inside the main lobby",
    "checked": "2026-11-20",
    "source": "walk"
  }}}
  ```

  `access` is `outside` (patio, plaza or outdoor walkway), `lobby` (inside the building) or `library` (past the library doors). `source` is `walk` (default) or `student-tip` for a tip someone confirmed. `npm run data` in `web/` checks every field and fails on unknown keys, missing `checked` dates, overlong text or a door more than 120 m from the room.
- `facilities.json` — generated by `data-pipeline/fetch_facilities.py` (standard library only) from the campus map's public building layer: official name, short label, alternative names, departments, use, region and outline centre of every non-residential, on-campus building.
- Buildings in `buildings.json` with `"source": "ucsc-facilities"` are added by `data-pipeline/build_facility_buildings.py` from `facilities.json` (classroom, lab, library, general-use and special-use buildings within 150 m of the walking graph that are not already curated). They have one `approach` point at the outline centre instead of doors, and no room list. Re-run it after `build_buildings.py`; it replaces its own earlier records.
